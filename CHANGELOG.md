# Changelog

## [1.0.0] - 2026-11-22

- Initial official Node.js SDK for Voipano Public API v1.
- Full coverage of the 23 documented Postman requests.
- Dual CommonJS/ESM entry points, TypeScript declarations, zero runtime dependencies.
- Scoped clients, typed error classes, secure binary download, and fail-closed webhook receiver.
- Built-in Node.js tests and GitHub Actions release workflow.
